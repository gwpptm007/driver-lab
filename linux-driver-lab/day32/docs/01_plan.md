# day32 详细计划

## 1. 今日主题
perf：热点采集与一个优化点

## 2. 核心目标
用 `perf record/report` 找到热点，完成一个具体优化点，并给出前后对比。

## 3. 今日最小闭环
- 输入：前置环境、设备后端、源码目录、guest 工具
- 过程：实施步骤、观察日志、校验行为
- 输出：原始证据、阶段结论、下一步输入

## 4. 实施步骤展开

### 1. 步骤 1
确定热点采集命令与 workload。

### 2. 步骤 2
输出热点函数列表和调用占比。

### 3. 步骤 3
实施一个最小优化，例如减少锁竞争、批处理、减少拷贝。

### 4. 步骤 4
回收优化前后数据并对比。
