# records

这里存放 `project-virtio-net-patch-and-trace` 的真实项目记录。

建议每一轮创建独立目录，例如：

```text
records/20260426_210000-virtio-net-patch-trace/
```

目录内建议至少包含：

- `before/`
- `after/`
- `trace/`
- `PATCH_POINT_NOTE.md`
- `PATCH_REVIEW_NOTE.md`
- `TRACE_REVIEW_NOTE.md`
- `FINAL_PROJECT_NOTE.md`
- `SUMMARY.md`
