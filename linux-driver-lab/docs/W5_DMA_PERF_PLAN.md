# W5 PCIe 作品线：把 DMA、mmap、bench、perf、ftrace 做真

## 1. W5 的定位

W5 不是简单延续 W4，而是把作品从“PCI 基本功闭环”推进到“性能与稳定性闭环”。

W4 解决的是：

- 设备可见
- BAR/MMIO
- 中断
- 用户态接口
- remove 与循环

W5 要解决的是：

- `dma_alloc_coherent`
- DMA 数据一致性
- `mmap` 零拷贝访问
- bench 指标化
- `perf` 热点分析
- `ftrace function_graph` 关键路径解释
- 并发稳定性与错误注入
- 最终 1~2 页报告

所以 W5 更像“性能与工程化交付周”。

---

## 2. 为什么 W5 切到 DMA-capable 后端

当前推荐切到 **DMA-capable PCI 设备**，建议优先 `QEMU EDU`。

原因不是追求设备多，而是因为 W5 的核心已经不是 BAR/MMIO 本身，而是：

- coherent DMA buffer
- DMA 地址传递
- 设备发起的数据搬运
- 完成通知
- 用户态 `mmap`
- benchmark
- 性能分析

这些内容更适合放到一个更像“教学型 DMA 设备”的后端上完成，这样文档和报告里的“DMA”才名副其实。

---

## 3. W5 学完后，你应该真正会什么

如果 W5 做顺了，最后你至少应该能讲清楚：

1. 为什么需要 `dma_set_mask_and_coherent` / `dma_alloc_coherent`
2. DMA 地址和 CPU 虚拟地址分别是什么
3. 用户态为什么能通过 `mmap` 看到 DMA buffer
4. `ioctl` 路径和 `mmap` 路径在吞吐/延迟上有什么差异
5. `perf record/report` 怎么找热点
6. `function_graph` 怎么抓关键路径并解释耗时
7. 稳定性压测和错误注入应该如何组织证据
8. 优化点怎么做前后对比

这已经非常接近岗位里的“驱动 + 性能分析 + 稳定性”表达了。

## 4. W5 整体实施路线

### D29：DMA coherent 跑通

目标：

- `dma_set_mask_and_coherent`
- `dma_alloc_coherent`
- 设备可使用 DMA 地址
- 做一次最小读写校验
- 无崩溃

### D30：`mmap`

目标：

- 把 DMA buffer 映射给用户态
- 用户态可以直接读写
- 完成“零拷贝访问路径”的最小闭环

### D31：bench

目标：

- 测吞吐
- 测延迟
- 输出 p50 / p99
- 记录 CPU 占用
- 形成可归档的报表

### D32：`perf`

目标：

- `perf record`
- `perf report`
- 找 1 个真实热点
- 写 1 个优化点
- 做优化前后对比

### D33：`ftrace`

目标：

- 开启 `function_graph`
- 抓关键路径时间窗口
- 解释主要耗时来自哪里
- 留 trace 截图与文字说明

### D34：稳定性

目标：

- 并发压测
- `rmmod/insmod` 1000 次
- 基础错误注入
- 回归结果归档

### D35：最终报告

目标：

- 1~2 页总结
- 指标、证据、结论、风险、回滚建议
- 形成最终可讲述版本

---

## 5. W5 建议最先沉淀的指标口径

为了避免最后 D35 才发现“数据口径不统一”，建议 W5 一开始就固定这些指标：

### 5.1 bench 指标

- 平均吞吐
- p50 延迟
- p99 延迟
- 错误次数
- 运行时长
- CPU 占用

### 5.2 perf 指标

- 最热点函数
- 栈上游/下游
- 采样占比
- 优化前后占比变化

### 5.3 稳定性指标

- 并发线程数/进程数
- 总执行轮次
- 成功率
- 错误分布
- 循环装卸成功率

---

## 6. W5 报告建议怎么写

最终 1~2 页报告建议至少包含：

1. **目标**：这轮要验证什么
2. **环境**：内核/QEMU/设备/工具
3. **方法**：DMA、mmap、bench、perf、ftrace、稳定性怎么测
4. **结果**：核心数据表
5. **优化**：至少 1 个优化点与前后对比
6. **风险**：还有哪些限制未解决
7. **回滚**：异常时回到哪个稳定版本

这样报告既像技术总结，也像交付件。

> 切到 DMA-capable PCI 设备，把 coherent DMA、mmap 零拷贝、bench、perf、ftrace、并发稳定性和最终报告真正做成一条有证据、有指标、有结论的作品闭环。
