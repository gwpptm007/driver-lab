# day25 详细计划

## 1. 今日主题
消息中断向量与中断统计

## 2. 核心目标
使用 `pci_alloc_irq_vectors()` 与 `request_irq()` 打通消息中断路径，验证 `/proc/interrupts` 计数增长。

## 3. 今日最小闭环
- 输入：前置环境、设备后端、源码目录、guest 工具
- 过程：实施步骤、观察日志、校验行为
- 输出：原始证据、阶段结论、下一步输入

## 4. 实施步骤展开

### 1. 步骤 1
调用 `pci_alloc_irq_vectors()`，flags 允许 `PCI_IRQ_MSIX | PCI_IRQ_MSI | PCI_IRQ_INTX`。

### 2. 步骤 2
使用 `pci_irq_vector()` 获取向量并 `request_irq()`。

### 3. 步骤 3
设计一个最小触发路径，让用户态或对端动作能触发中断。

### 4. 步骤 4
在 ISR 中更新原子计数并导出状态。
