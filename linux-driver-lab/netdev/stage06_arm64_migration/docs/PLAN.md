# stage06_arm64_migration / PLAN

## 目标

把前面已经完成的 netdev 主线，迁移到 ARM64 / QEMU 运行链路中，并把整套方法收口成：

- 平台可切换
- 工具链可切换
- 构建链可切换
- 运行链可切换
- 报告可比较

## 阶段重点

- 不再新增复杂数据面功能
- 不再扩充新的 netdev 核心语义
- 重点处理平台差异、构建差异、兼容差异、报告差异

## 验收方向

1. 至少有一条 ARM64 build 路径跑通
2. 最好有一条 ARM64 QEMU run 路径跑通
3. 能输出 host vs arm64 的差异报告
4. 兼容层头文件可复用到 stage04/后续驱动
