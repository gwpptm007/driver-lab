## 修复记录

测试过程中发现并修复的问题：

### 问题1: userspace 工具编译失败（Ubuntu 22.04 glibc）
- **现象**: `struct ifreq` 大小未知
- **原因**: glibc 系统需要 `_GNU_SOURCE` 才能在 `<sys/socket.h>` 之前看到完整定义
- **修复**:
  - 添加 `#define _GNU_SOURCE`
  - 调整头文件包含顺序：`socket.h → ioctl.h → if.h`
  - 添加 `#include <unistd.h>`（close 函数）

### 问题2: 内核模块编译失败（Linux 6.8.0 API 变更）
- **现象**: `u64_stats_update_begin_irqsave` 参数个数不匹配
- **原因**: Linux 6.8 将 `irqsave` 版本改为返回 `unsigned long`（flags），不再通过参数输出
- **修复**:
  ```c
  // 旧代码（Linux 5.x）：
  u64_stats_update_begin_irqsave(&priv->syncp, flags);

  // 新代码（Linux 6.8）：
  flags = u64_stats_update_begin_irqsave(&priv->syncp);
  ```
- **同时修复**:
  - `u64_stats_fetch_begin_irq` → `u64_stats_fetch_begin`
  - `u64_stats_fetch_retry_irq` → `u64_stats_fetch_retry`
