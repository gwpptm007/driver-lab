# day30：mmap 零拷贝访问 DMA buffer

## 1. 今日定位

- 周期：W5
- 后端设备：QEMU EDU（DMA-capable）
- 当日目标：把 DMA buffer 映射给用户态，实现零拷贝读写并验证用户态可访问。

这一天不追求“大而全”，只追求把当天的关键链路做通，并且把证据沉淀下来。

---

## 2. 你今天真正要学会什么

- 理解字符设备 `mmap` 回调与页对齐要求
- 理解为什么不是所有内核缓冲都能随便 `mmap`
- 知道用户态映射后需要怎样约束访问边界

---

## 3. 推荐推进顺序

1. 梳理 DMA buffer 的页属性与映射方式。
2. 实现 `mmap` 回调与长度/offset 校验。
3. 用户态工具新增 mmap 模式并完成读写校验。
4. 记录映射失败与非法参数路径。

---

## 4. 当日验收

- `mmap` 成功
- 用户态可访问并读写验证
- 非法映射请求被明确拒绝
