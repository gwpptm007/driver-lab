# day31 records

这里存放 Day31 每次真实运行的原始证据。

建议每次运行都使用新的 `RUN_ID`，例如：

```bash
export RUN_ID=day31-local-002
sudo -E make run
```

建议至少保留：

- `serial.log`
- `qemu.stderr.log`
- `qemu-command.txt`
- `lspci-nn.txt`
- `lspci-vv-nn.txt`
- `tool-info.txt`
- `mmap-verify.txt`
- `bench-ioctl.txt`
- `bench-mmap.txt`
- `bench-dma.txt`
- `bench-all.txt`
- `run-result.txt`
- `dmesg-driver.txt`
- `run-summary.md`
