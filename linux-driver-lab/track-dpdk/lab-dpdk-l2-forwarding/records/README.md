# records

每次执行 `00_check_env.sh` 会创建新的记录目录：

```text
records/YYYYMMDD_HHMMSS-dpdk-l2-forwarding/
```

核心文件：

```text
ENV_CHECK.txt
BUILD.log
PREPARE_VMXNET3.txt
L2FWD_SINGLE_PORT.log
L2FWD_SINGLE_PORT_COMMAND.txt
L2FWD_TWO_PORT.log
L2FWD_VDEV_NULL_PAIR.log
COLLECT_STATS.txt
REVIEW_BUNDLE.md
SUMMARY.md
RESULT.md
COMMANDS.md
```
