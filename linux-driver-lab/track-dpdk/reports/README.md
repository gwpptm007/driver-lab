# track-dpdk reports

本目录存放 `track-dpdk` 的阶段性总结、最终报告、面试材料和简历素材。

## final/

`final/` 是 DPDK track 阶段性总收口材料：

- `DPDK_TRACK_REPORT.md`：DPDK track 总报告
- `DPDK_PROJECT_PORTFOLIO.md`：作品集说明
- `DPDK_INTERVIEW_NOTES.md`：面试讲法
- `DPDK_RESUME_MATERIAL_FINAL.md`：简历素材
- `DPDK_BACKLOG.md`：后续补强项

根目录只保留 `README.md`、`ROADMAP_NEXT.md`、`docs/`、各 lab/project 目录，避免把总结报告散放在 track 根目录。
