# START HERE

如果你是第一次打开 `day21/`，建议按下面顺序看：

1. `README.md`  
   先理解 Day21 现在已经进入最终提交版状态。

2. `FINAL_SUBMISSION.md`  
   这是 Day21 当前最像“提交说明”的入口文件。

3. `output/day21_report_submission.md`  
   这是当前最适合直接交付、直接讲解的一版正文。

4. `output/day21_report_onepager.md`  
   这是更适合快速回顾、快速讲解的一页版。

5. `output/day21_acceptance_checklist.md`  
   用来快速判断 Day21 当前是否达到提交状态。

6. `docs/04_data_sources_and_constraints.md`  
   看这份报告的取数边界和结论限制，避免误读。

7. `docs/08_final_acceptance.md`  
   看 Day21 当前为什么可以按“最终提交版”验收。

8. `run_day21_report.sh`  
   如果你想重新生成 Day21 输出，可以直接从这里开始。
