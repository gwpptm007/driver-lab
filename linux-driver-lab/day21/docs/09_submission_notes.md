# Day21 提交版说明

## 1. 为什么还要有“提交版”

`day21_report_final.md` 更像完整正式版，适合完整阅读。

`day21_report_submission.md` 的目的，是把最终最该说的话压得更利索：

- 先说最稳结论
- 再说当前推荐配置
- 再说 Day20 当前真实状态
- 最后给出回滚与下一步建议

这样更适合作为“最终提交物正文”。

## 2. 提交版和正式版的关系

- `day21_report_final.md`：更完整、更平衡
- `day21_report_submission.md`：更适合交付、讲解、复盘
- `day21_report_onepager.md`：更适合快速看和快速讲

## 3. 当前提交版的边界

当前提交版仍然坚持两个边界：

1. **最稳收益只重点讲 D15 → D16。**
2. **D18 与 Day20 的结论都要带边界说明。**

这不是保守，而是为了避免把“当前最终形态成立”和“所有数字都可无条件横向比较”混成一句话。
