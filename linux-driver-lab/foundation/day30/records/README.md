# day30 records

这里存放 Day30 每次真实运行的原始证据。

建议每次运行都使用新的 `RUN_ID`，例如：

```bash
export RUN_ID=day30-local-002
sudo -E make run
```

建议至少保留：

- `serial.log`
- `qemu.stderr.log`
- `qemu-command.txt`
- `lspci-nn.txt`
- `lspci-vv-nn.txt`
- `tool-info.txt`
- `invalid-mmap-len.txt`
- `invalid-mmap-offset.txt`
- `mmap-verify.txt`
- `run-result.txt`
- `dmesg-driver.txt`
- `run-summary.md`
